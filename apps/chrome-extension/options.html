GitHub 上傳設定

對話會上傳到你自己的私人（private）倉庫。設定只存在這台電腦的瀏覽器裡，不會同步到其他地方。

怎麼建立存取金鑰

  1. 在 GitHub 先建立一個私人倉庫，並勾選「Add a README」，讓倉庫不是空的。
  2. 到 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  3. Expiration（到期日）：建議 90 天，到期再換新的。
  4. Repository access：選 Only select repositories，只勾你的分析倉庫。
  5. Permissions → Repository permissions → Contents：選 Read and write。其他都不用開。
  6. 產生後複製金鑰，貼到上面的欄位。
