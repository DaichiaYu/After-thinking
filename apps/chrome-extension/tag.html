ZIP 可直接開啟且自帶附件，不用 GitHub；即使下載檔被改成 UUID、沒有 .zip 副檔名，也能直接選取。舊版檔案要接著標，可以同時選 conversation.jsonl 和 outline.json；有 AI 給的 outline.ai.json 也可以一起選。

讓其他 AI 協助預先標記

這裡是選用功能：請其他 AI 先產生標記建議，再匯回這個工作台讓你審查。你也可以完全跳過，直接自己標記。AI 的建議會用虛線顯示，你可以接受、修改或刪掉；沒動的會當作你同意，但會記下這是 AI 標的、你沒有反駁。

方式 A｜讓 AI 將建議寫到 GitHub

適合能讀寫 GitHub 的 AI，例如 Claude Code、Codex、有接 GitHub 的 Claude。「複製指令」只給對話位置與原文指紋；完整規則會檢查並寫入你資料倉庫的 guides/outline-ai.md。確認寫入狀態後再貼給 AI，讓它只產生 outline.ai.json，不要改你的標記和原文。

方式 B｜下載對話與規則，請其他 AI 產生建議

  1. 下載給 AI 的請求檔，內含對話及標記規則（這不是標記結果檔）。
  2. 把檔案和下面這句話一起丟給 AI。
  3. 取得 AI 回傳的 outline.ai.json 後，在此匯入並審查；不必連 GitHub。

若你只想自己標記，不需要下載這份請求檔。從標記頁入口載入 conversation.jsonl，完成後按「下載 outline.json」即可。
