AFTER-THINKING / MOBILE

接續你的對話標記。

連接你自己選擇的 GitHub 資料倉庫，閱讀與編輯 AT 原本的標記檔。不需要安裝 Chrome 擴充功能。

Token 需要該資料倉庫的 Contents：Read and write。沒勾「記住這台裝置」時只保存在目前分頁的記憶體中，關閉或重新整理就會清除。不要將 Token 貼到公開 Issue、程式碼或網址。

或
為什麼需要 Token？

勾選「記住這台裝置」後，Token 只存在這個瀏覽器的本機儲存空間，不會上傳到任何地方；隨時可以在「更多」裡忘記這台裝置。也可以改讓手機的密碼管理員記住它。

GitHub Pages 是靜態網站，不能在公開前端安全保存 OAuth Client Secret。此版本採用只授權使用者指定倉庫的 Token；未來可以透過獨立 GitHub App 授權服務取代手動輸入。
