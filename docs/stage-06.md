# Stage 6

Input: usable Stage 2, usable Stage 3, usable Stage 5, applicable active corrections, and source lookup when needed.

Output: `analysis/06-next-directions.md`.

Each formal direction stores an ID, related gap, next question, reason, expected impact, required input, and priority. Include required run and completion metadata.

Stage 6 becomes `completed` only after its criteria in `stage-exit-criteria.md` are met. If no existing Gap warrants continuation, record that no next discussion direction is required. An empty direction set is valid.

Review policy is `none`; successful completion uses `not_required`.

When Stage 6 is usable, set `analysis_status: complete`. This is a successful terminal state and does not require publication or publishable material.
