# Simple discussion example

This fictional, de-identified workspace shows one complete After-thinking run. It is an implementation example, not user data.

The example demonstrates:

- stable source IDs with separate `order`;
- a Stage 1 correction persisted as `CR001` and applied only by its owning Stage;
- mandatory confirmation evidence for Stages 1–2;
- canonical `T`, `R`, `C`, `CS`, `G`, and `D` objects;
- risk-based Stages completing with `not_required`;
- traceability from a Claim to a Gap to a next Direction;
- structured terminal `next_action`.
